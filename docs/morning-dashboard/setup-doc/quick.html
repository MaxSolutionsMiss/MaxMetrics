Left sidebar, under the company name with a building icon. Not the blue cloud above it.

Do not skip this. Without it Windows keeps files in the cloud and the dashboard reads them as empty.

Double-click it in that folder. An old copy saves boxes back empty over everybody else's.

Top-left of the dashboard. Pick the folder you found in step 5.

9

The most important click here. "View files" looks safe and silently stops the PC saving. Boardroom screen: see overleaf.

The boardroom PC, and when something looks wrong

The boardroom screen

Same nine steps, two differences.

It needs a company account signed in. That machine is not on the domain, so no account is on it. Syncing does not need domain membership — it only needs somebody to sign into OneDrive on it once, with a Max Solutions account that can see the library. Use a shared account, never a person's: a wall PC signed in as somebody who has left is a problem waiting to happen.

At step 9, answer View files instead — if the screen only ever shows the morning. A machine that cannot write cannot damage anybody's morning, and will never fail in front of the room trying. If people do type into it during the meeting, answer Edit files like any other PC.

Each morning: open the dashboard and press Present. It goes full screen, reads the folder, writes nothing, and refreshes every fifteen seconds — so comments typed at people's desks appear on the wall on their own.

What each symptom actually means

Red bar: no shared folder pickedSteps 8 and 9 not done here, or Chrome dropped the permission after a restart. Press Choose folder.
Red bar: this is an old copySomebody is running a newer version. Close the tab and open the copy in the SharePoint folder.
NOT shared — saved on this PC onlyThe write was refused. Almost always View files at step 9, or the account is read-only on the library. Nothing is lost.
Boxes empty that should not beAlways keep on this device was skipped at step 6. Set it and reopen.
One PC shows a different dayThat computer's clock is wrong, so it reads a different day's file. Check this PC says so outright.
Files like 2026-08-25-SOMEPC.jsonTwo people saved in the same sync minute and OneDrive kept both. The dashboard folds them back in by itself — nothing to do.
A comment went missingSharePoint keeps version history on every one of these files: right-click the day's file on the site → Version history.
Replacing the dashboard itselfIt is one file. Drop the new Morning_Dashboard.html into the SharePoint folder. Everybody has it next time they open it.
