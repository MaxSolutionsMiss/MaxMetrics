Morning Dashboard
Do this first — once on each computer

Press “Choose folder” before you type anything

Z:\Morning Dashboard\Data

Skip it and everything you type stays on that one PC. The screen looks completely normal — your numbers are there, your comments are there — but nobody else sees any of it, and it never reaches the folder the meeting reads from.

You only ever do this once per computer — after that the dashboard remembers.

How to tell at a glance

If the folder has not been picked, the dashboard says so across the top:

No shared folder picked on this PC. Nothing typed this morning will reach anybody else until one is.

No red bar means you are set up and can carry on. If you do see it, click Choose the folder in the bar and pick Data — nothing you have already typed is lost.

Then, every morning

1
Open the dashboard

From Z:\Morning Dashboard. Don't copy it to your desktop — a copy stops sharing with everybody else.

2
Check the date

It opens on today. Change it at the top if you are filling in a different day.

3
Type the numbers and the comments

The first time you comment it asks your name and initials, then never again on that computer.

4
Press Save as you go

Save shares what you have so far. Anyone else with the dashboard open sees it within about fifteen seconds.

5
Press Publish / Present for the meeting

The boxes and buttons come off the screen and it becomes something to read on the wall.

If it says it cannot write to the folder Nothing is lost — the morning is saved on that PC. Take a photo of the message and send it on. It usually means that computer can read the folder but not save into it, which is a permission on the drive rather than anything you did.
Everything lives in Z:\Morning Dashboard — no login, no internet, nothing to install. Folder saving needs Chrome or Edge; the dashboard will say so if you are in another browser.
