Morning Dashboard
Do this first — once on each computer

Press “Choose folder” before you type anything

Z:\Morning Dashboard\Data

Skip it and everything you type stays on that one PC. The screen looks completely normal — but nobody else sees any of it, and it never reaches the folder the meeting reads from.

The folder is then remembered. Chrome asks permission again each restart — one click, below.

Every morning: glance at the top of the page

A blue bar — Chrome forgets the permission each time it restarts, so it asks again. Click the button. No folder to find, nothing to type.

Reconnect the shared folder. This PC still knows which folder to use.

A red bar — this computer has never been set up. Click the button and pick Data.

No shared folder picked on this PC. Nothing typed this morning will reach anybody else until one is.

No bar at all — you are ready, carry on. Either way, nothing you have already typed is ever lost.

Then, every morning

1
Open it from Z:\Morning Dashboard

Never copy it to your desktop — a copy stops sharing with everybody else. It opens on today's date.

2
Type the numbers and the comments

The first comment asks your name and initials, then never again.

3
Press Save as you go

Anyone else with the dashboard open sees it within about fifteen seconds.

4
Press Publish / Present for the meeting

The boxes and buttons come off and it becomes something to read on the wall.

If it says it cannot write to the folder Nothing is lost — the morning is saved on that PC. Take a photo of the message and send it on. Also: Export makes a personal backup called dashboard-<date>.json. Putting that in the folder does not save the morning — nobody reads those.
Everything lives in Z:\Morning Dashboard — no login, no internet, nothing to install. Needs Chrome or Edge.
