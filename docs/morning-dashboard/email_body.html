Morning Dashboard
Revised setup — it has moved to SharePoint

Hi all,

We ran into problems running the dashboard from the Z: drive that could not be fixed on the drive itself. It is why a few mornings went missing, and why some comments saved and others did not.

The dashboard now lives on the Mississauga SharePoint. Same dashboard, same screen — better foundation underneath.

What I need from you: about two minutes, once, on your own PC. You will not have to do it again.
1
Open the SharePoint folder and sign in
MaxSolutions-Mississauga → Documents → Daily Morning Dashboard. Use your work account.
2
Go into the folder
Double-click into it so you can see the files. Syncing from the level above drags down every other folder in Documents.
3
Click Sync in the toolbar
Windows will offer to open OneDrive — say yes, and sign in again if it asks.
4
Wait for the tick
The OneDrive cloud at the bottom-right of your screen. On a folder this small it takes seconds.
5
Find it in File Explorer
Left sidebar, under Max Solutions, Inc — the building icon, not the blue cloud above it.
6
Right-click the folder → Always keep on this device
Skip this and Windows keeps your files in the cloud. The dashboard reads them as blank, and it looks exactly like somebody wiped the morning.
7
Open Morning_Dashboard.html from that folder
Never a copy on your desktop or in Downloads. An old copy saves boxes back empty over everybody else’s.
8
Press Choose folder in the dashboard
Top-left. Pick the same folder you found in step 5. The red bar then goes for good.
9
Chrome asks what it may do → Edit files
“View files” looks like the safe answer. It is not — the dashboard will read the morning perfectly and silently refuse to save anything you type.
A few other things
•  Stop using Z:. Anything saved there from now on will not reach the meeting.
•  Never keep your own copy of the dashboard. Open it from the SharePoint folder every time. If you are on an old copy the page now tells you so in a red bar.
•  If it ever says “NOT shared — saved on this PC only”, nothing is lost — your morning is still on that machine. Send me a photo of the message.
•  The boardroom screen is being sorted separately. It needs an account it does not have yet, so do not spend time on it.
